# Poppie's Navy Journal

Interactive transcription viewer and PDF editions for Poppie's Navy journal.

## GitHub Pages

The GitHub Pages site is in `docs/`.

- Open `docs/index.html` locally to preview the static viewer.
- The published site can use GitHub Pages with source set to the `docs/` folder.
- The downloadable PDF is included at `docs/downloads/Poppies_Navy_Journal_revised.pdf`.

## Project Files

- `docs/` - GitHub Pages-ready interactive viewer.
- `transcriptions/` - Markdown transcription sources.
- `output/pdf/` - generated PDF editions.
- `Poppies Philippine Dairy Two facing pages - full.pdf` - source scan.
